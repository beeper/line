## Comparison boundary

“Before” below means upstream `45a48b9b3b57330d99d326d443f9a9fc8725a48f`,
the last upstream commit integrated into this branch. “After” is PR source
`81f502150b88e681d2703239df608b1b38ccc2d6` plus documentation-only updates.
It is **not** a claim that today's upstream lacks every improvement below.
On 2026-11-02, upstream was `10e0a5fdd18440d4b5c23b5dd0f9cc75cc7dd3fe`;
GitHub reports a conflict. A read-only `git merge-tree` check located the
content conflict in `pkg/connector/client.go`. Upstream #294 (transient token
recovery), #298 (persistent E2EE reconnect prompt), #299 (avatar concurrency),
#295 (send/media error mapping), #302 (media size handling), and #303 (stickers)
must be preserved and revalidated during a future integration/split. This
documentation update neither resolves that conflict nor changes runtime code.
